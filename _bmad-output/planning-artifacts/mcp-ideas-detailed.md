## 아이디어 1: 시니어 라이프 케어

> **"어르신의 일상을 함께하는 AI 동반자"**

### 핵심 컨셉
- 복잡한 복지 제도를 **대화형으로 쉽게** 안내
- 어르신 눈높이에 맞춘 **큰 글씨, 쉬운 말**
- 자녀가 부모님 대신 조회해도 유용

---

### Tools 상세 (예상 12개)

| Tool명 | 기능 | 입력 | 출력 |
|--------|------|------|------|
| `check_basic_pension` | 기초연금 수급자격 확인 | 나이, 소득수준 | 자격여부, 예상금액 |

| `get_welfare_programs` | 오늘의 복지관 프로그램 | 지역, 날짜 | 프로그램 목록, 시간, 신청방법 |
| `check_health_screening` | 무료 건강검진 대상 확인 | 나이, 성별 | 검진항목, 가까운 병원 |

| `long_term_care_grade` | 장기요양등급 판정 안내 | 건강상태 | 예상등급, 신청방법 |

    - 소득인정액이 단독가구 213만원 이하면 받으실 수 있어요

> **"똑똑한 장보기, 가계부담을 덜어드려요"**

### 핵심 컨셉
- **실시간** 농산물 가격 정보
- **비교 분석**으로 합리적 소비
- **제철 식재료** 추천

---

### Tools 상세 (예상 11개)

| Tool명 | 기능 | 입력 | 출력 |
|--------|------|------|------|
| `get_price` | 농산물 현재가 조회 | 품목명 | 도매가, 소매가, 등급별 |
| `compare_price` | 가격 비교 | 품목, 기간 | 가격 추이, 그래프 |
| `find_cheap_market` | 저렴한 시장 찾기 | 위치, 품목 | 시장별 가격 비교 |
| `market_vs_mart` | 전통시장 vs 마트 | 품목 | 가격 비교, 추천 |
| `seasonal_recommend` | 제철 식재료 추천 | 월 | 제철 품목, 가격대 |
| `price_alert` | 가격 알림 설정 | 품목, 목표가 | 알림 등록 |
| `basket_calculator` | 장바구니 계산 | 품목 리스트 | 예상 비용 |
| `weekly_trend` | 주간 가격 동향 | - | 급등/급락 품목 |
| `price_forecast` | 가격 예측 | 품목 | 향후 가격 전망 |
| `recipe_cost` | 레시피별 재료비 | 요리명 | 필요재료, 총 비용 |
| `find_traditional_market` | 전통시장 찾기 | 위치 | 시장 목록, 특산품 |

    ─────────────────────────

    시장 위치 알려드릴까요?

#### 시나리오 3: 제철 추천
```
🌿 사용자: "1월에 뭐 먹으면 좋아?"

    🥬 채소

    🍊 과일

    • 딸기 - 하우스 딸기 시즌
    • 한라봉 - 이때가 가장 맛있어요

    🐟 수산물
    • 굴 - 겨울 굴이 최고!
    • 과메기 - 포항 과메기 제철
    • 대게 - 영덕대게 시즌

    💰 지금 가장 저렴한 건?
    → 무, 귤, 시금치 (전주 대비 10%↓)
```

## 아이디어 5: 모두의 이동 (배리어프리 내비게이션)

> **"누구나 자유롭게 이동할 수 있는 세상"**

### 핵심 컨셉
- **교통약자**를 위한 맞춤형 이동 안내
- **배리어프리 시설** 정보 제공
- **휠체어/유모차** 친화적 경로

---

### Tools 상세 (예상 12개)

| Tool명 | 기능 | 입력 | 출력 |
|--------|------|------|------|
| `find_low_floor_bus` | 저상버스 찾기 | 노선번호, 정류장 | 저상버스 도착시간 |
| `accessible_subway` | 엘리베이터 있는 역 | 출발역, 도착역 | 경로, 엘리베이터 위치 |
| `wheelchair_route` | 휠체어 경로 안내 | 출발, 도착 | 경사도 낮은 경로 |
| `find_accessible_toilet` | 장애인 화장실 찾기 | 위치 | 화장실 목록, 상태 |
| `find_barrier_free_place` | 배리어프리 시설 | 위치, 종류 | 인증시설 목록 |
| `call_taxi_disabled` | 장애인 콜택시 | 위치, 목적지 | 예약 안내/연결 |
| `companion_service` | 동행 서비스 안내 | 지역 | 서비스 신청 방법 |
| `discount_info` | 교통약자 할인 정보 | 교통수단 | 할인율, 이용방법 |
| `accessible_parking` | 장애인 주차장 | 위치 | 주차장 위치, 빈자리 |
| `report_obstacle` | 이동 장애물 신고 | 위치, 내용 | 신고 접수 |
| `rental_wheelchair` | 휠체어 대여소 | 위치 | 대여소 목록, 재고 |
| `sign_language_service` | 수어 통역 서비스 | 상황 | 서비스 연결 |

#### 시나리오 2: 휠체어 경로
```
🦽 사용자: "성수역에서 서울숲까지 휠체어로 가려면?"

🤖 AI: 🦽 휠체어 친화 경로 안내해요!

    📍 성수역 → 서울숲 (약 850m)

    ✅ 추천 경로 (경사도 낮음)
    ─────────────────────────
    1. 성수역 3번 출구 (엘리베이터 ✓)
    2. 성수이로 따라 직진 (평지)
    3. 서울숲 2번 출입구 (경사로 ✓)

    ⏱️ 예상 소요: 휠체어 약 15분
    📐 최대 경사도: 5% (완만)

    ⚠️ 주의구간:
    성수역 2번 출구는 계단만 있어요!

    중간에 장애인 화장실:
    📍 서울숲역 내 (엘리베이터 옆)
```

#### 시나리오 3: 배리어프리 식당

    2. 🍜 맛있는 칼국수
       ✅ 휠체어 진입 가능
       ⚠️ 화장실 협소
       📍 성수동 234-5 | ☎️ 02-2345-6789

    3. 🍕 피자스토리

## 추천 순위

### 1순위: 시니어 라이프 케어 또는 장바구니 물가 도우미

**이유:**
1. 기존 MCP에 전혀 없는 영역
2. 사회적 가치 + 실용성 동시 충족
3. 공공데이터 API 풍부하게 존재
4. 심사위원에게 인상적인 스토리텔링 가능

**이유:**
1. ESG 가치, 사회적 임팩트
2. 차별화된 타겟층
3. 카카오의 사회공헌 방향과 일치

### 3순위: 재난안전 도우미

**이유:**
1. 생명과 직결된 서비스
2. 카카오톡 연동 시너지
3. 뉴스/이슈 연계 홍보 용이
