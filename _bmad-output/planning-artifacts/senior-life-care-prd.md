# 시니어 라이프 케어 MCP - 제품 요구사항 문서 (PRD)

> **버전:** 1.0
> **작성일:** 2025-12-31
> **프로젝트:** playmcp-kakao
> **대회:** MCP Player 10

---

## 1. 제품 개요

### 1.1 제품명
**시니어 라이프 케어 (Senior Life Care)**

### 1.2 슬로건
> "어르신의 일상을 함께하는 AI 동반자"

### 1.3 핵심 가치
- **쉬움**: 복잡한 복지 제도를 대화형으로 쉽게
- **따뜻함**: 단순 정보 전달이 아닌 정서적 교감
- **실용성**: 일상에서 매일 사용할 수 있는 서비스

---

## 2. 타겟 사용자

### 2.1 주요 타겟
- **65세 이상 어르신**: 직접 복지 정보를 얻고 싶은 분
- **시니어 자녀 (40~60대)**: 부모님 대신 정보를 찾는 분

### 2.2 사용자 페르소나

#### 페르소나 1: 김순자 어르신 (72세)
- 혼자 살며 기초연금 수령 중
- 스마트폰 카카오톡은 능숙하게 사용
- 복지관 프로그램에 관심 있지만 정보 찾기 어려움

#### 페르소나 2: 박영수 씨 (48세)
- 지방에 계신 어머니(75세) 돌봄
- 어머니 대신 복지 혜택 알아보고 싶음
- 바쁜 직장인이라 빠른 정보 습득 필요

## 3. 기능 명세 (20개 Tools)

### 3.1 카테고리: 연금/수당 (4개)

| Tool명 | 기능 | 입력 | 출력 |
|--------|------|------|------|
| `check_basic_pension` | 기초연금 수급자격 및 예상금액 확인 | 나이, 소득수준, 가구형태 | 자격여부, 예상금액, 신청방법 |
| `calculate_national_pension` | 국민연금 예상 수령액 계산 | 가입기간, 평균소득 | 예상 수령액, 수령 시기 |
| `check_disability_pension` | 장애인연금 자격 확인 | 장애등급, 소득 | 자격여부, 지원금액 |
| `check_veteran_benefits` | 국가유공자 혜택 조회 | 유공자 유형 | 혜택 목록, 신청방법 |

### 3.2 카테고리: 건강/의료 (5개)

| Tool명 | 기능 | 입력 | 출력 |
|--------|------|------|------|
| `check_health_screening` | 무료 건강검진 대상 및 일정 | 나이, 성별, 지역 | 검진항목, 가까운 병원, 예약방법 |
| `find_dementia_center` | 치매안심센터 찾기 | 위치(시/구) | 센터정보, 서비스, 연락처 |
| `dementia_self_check` | 치매 자가진단 (KDSQ) | 질문 응답 | 점수, 결과해석, 권고사항 |
| `find_senior_hospital` | 노인전문병원 찾기 | 위치, 진료과목 | 병원목록, 평점, 연락처 |
| `check_medical_expense_support` | 의료비 지원제도 안내 | 소득수준, 질환 | 지원제도, 신청방법 |

### 3.3 카테고리: 돌봄/요양 (4개)

| Tool명 | 기능 | 입력 | 출력 |
|--------|------|------|------|

| `check_caregiver_support` | 가족요양보호사 지원 | 가족관계 | 지원조건, 급여, 신청방법 |

### 3.4 카테고리: 여가/문화 (3개)

| Tool명 | 기능 | 입력 | 출력 |
|--------|------|------|------|

## 4. 사용자 시나리오

### 시나리오 1: 기초연금 상담
```
👴 사용자: "나 올해 66살인데 기초연금 받을 수 있어?"

🤖 AI: 네, 어르신! 만 65세 이상이시니 기초연금 대상이세요.

    📋 몇 가지만 확인할게요:

    1️⃣ 혼자 사세요, 배우자분이랑 같이 사세요?
    2️⃣ 한 달 소득이 대략 얼마나 되세요?

    이것만 알려주시면 받으실 수 있는지, 얼마나 받으실 수 있는지 바로 알려드릴게요!
```

### 시나리오 2: 치매 걱정
```
👵 사용자: "요즘 깜빡깜빡하는게 심해졌어"

🤖 AI: 걱정되시죠 😊 많은 분들이 비슷한 고민을 하세요.

    두 가지 방법이 있어요:

    1️⃣ 간단한 자가진단 (5분)
       - 지금 바로 해볼 수 있어요
       - 10개 질문에 답하시면 돼요

    2️⃣ 전문 검사 (무료)
       - 가까운 치매안심센터에서 받으실 수 있어요
       - 📍 성동구 치매안심센터 (02-2286-7788)

    어떤 걸로 해볼까요?
```

### 시나리오 3: 자녀가 대신 문의
```
👨 사용자: "우리 어머니가 75세신데 받을 수 있는 혜택 뭐가 있어요?"

🤖 AI: 네, 어머니 혜택 찾아드릴게요! 👵

    몇 가지만 여쭤볼게요:

    1️⃣ 어머니 혼자 사세요?
    2️⃣ 건강은 어떠세요? (거동 불편하신지)
    3️⃣ 기초연금은 받고 계세요?

    알려주시면 맞춤 혜택 정리해드릴게요!
```

### 시나리오 4: 복지관 프로그램
```
👴 사용자: "집에만 있으니까 심심해. 뭐 할 거 없을까?"

🤖 AI: 그러시구나! 동네에 재미있는 프로그램 많아요 😊

    📍 어르신 동네가 어디세요?

    ---
    (성동구라고 하시면)

    🏛️ 성동구립 행복복지관 (도보 10분)

    이번 주 프로그램:
    🎵 노래교실 - 화/목 10시 (무료)
    🧘 건강체조 - 매일 14시 (무료)
    🎨 서예교실 - 수 15시 (재료비 5천원)
    💻 스마트폰 배우기 - 금 10시 (무료)

    관심 있는 거 있으세요?
```

## 5. 기술 스택

### 5.1 개발 환경
- **언어**: TypeScript
- **런타임**: Node.js 18+
- **MCP SDK**: @anthropic-ai/sdk 또는 @modelcontextprotocol/sdk

### 5.2 활용 공공데이터 API

| API명 | 제공기관 | 용도 | 인증방식 |
|-------|----------|------|----------|
| 기초연금 수급자격 API | 보건복지부 | 연금 자격 확인 | API Key |
| 노인복지시설 현황 API | 공공데이터포털 | 복지관/경로당 조회 | API Key |
| 치매안심센터 API | 중앙치매센터 | 센터 위치/서비스 | API Key |
| 건강검진 대상자 API | 국민건강보험 | 검진 일정 | API Key |
| 장기요양등급 API | 국민건강보험 | 요양등급 정보 | API Key |
| 노인돌봄서비스 API | 한국사회보장정보원 | 돌봄서비스 조회 | API Key |
| 요양기관 정보 API | 건강보험심사평가원 | 요양원 정보 | API Key |

### 5.3 프로젝트 구조

## 6. 차별화 전략

### 6.1 UX 차별화
1. **어르신 친화적 언어**: 존댓말, 쉬운 용어, 친근한 이모지
2. **단계별 안내**: 한 번에 많은 정보 제공 X, 대화하며 안내
3. **공감 표현**: "걱정되시죠", "그러시구나" 등 정서적 교감

### 6.2 기능 차별화
1. **자녀 모드**: "우리 어머니/아버지 대신 알아봐줘"
2. **맞춤 추천**: 상황 파악 후 적합한 혜택 자동 추천
3. **원스톱 안내**: 자격확인 → 신청방법 → 필요서류 → 가까운 기관

### 6.3 기술 차별화
1. **실시간 데이터**: 공공API 연동으로 최신 정보
2. **지역 맞춤**: 사용자 위치 기반 가까운 시설 안내
3. **계산기 기능**: 연금/급여 예상액 자동 계산
